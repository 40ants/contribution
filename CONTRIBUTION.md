# Contribution rules

## Issues

Before you create an issue, check for similar issues.

For a bug report, include these details:

- Steps to reproduce the bug.
- The expected result.
- The actual result.

## Pull requests

A pull request (PR) must address one task.

Each PR must meet these requirements:

- Describe the changes.
- Link the PR to the related issue.
- Include tests for the changes.
- Update the documentation files in `docs/`.
- Update the changelog in `docs/changelog.lisp`.

Do not include `ChangeLog.md` or `README.md` files in a PR.

## Common Lisp code

Follow the [Google Common Lisp Style Guide](https://google.github.io/styleguide/lispguide.html) for Common Lisp code.
